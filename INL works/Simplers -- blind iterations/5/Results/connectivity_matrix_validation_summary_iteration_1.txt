Connectivity matrix validation summary - Document 5, Iteration 1

Ground truth normalization:
The GT file is an edge list, so it was normalized into an undirected set of component-to-component edges before validation. The extracted CSV files were adjacency matrices and were normalized into the same undirected edge-set format. Diego/Jennifer round matrix files and final_connectivity_matrix.csv were evaluated.

GT after normalization: 56 undirected edges across 55 component names.

Document-specific normalization:
For this document, MCC-21A-480V-3PH and MCC-21B-480V-3PH were treated as drawing-faithful aliases for the GT nodes MCC-21A and MCC-21B. The metrics CSV uses this alias-normalized scoring, so those MCC labels are not penalized.

Main reason the raw scores were not perfect:
The dominant raw-score issue is close-but-not-perfect component naming for MCC nodes. The extracted matrices use MCC-21A-480V-3PH and MCC-21B-480V-3PH, while the GT uses MCC-21A and MCC-21B. Under exact validation, this creates 14 false positives and 14 false negatives in Jennifer Round 1, Diego Round 2, Jennifer Round 2, and the final matrix, even though the physical MCC connectivity is otherwise consistent.

Close-but-not-perfect component names driving most of the score drop:
- MCC-21A-480V-3PH should map to MCC-21A
- MCC-21B-480V-3PH should map to MCC-21B

Raw component-name effects:
- Extra extracted names across the matrices: MCC-21A-480V-3PH, MCC-21B-480V-3PH, RPS-CH-A-CONTROL-LANE, RPS-CH-B-CONTROL-LANE, VOLTAGE-SIG-A, VOLTAGE-SIG-B.
- Missing exact GT names across the matrices: MCC-21A, MCC-21B.

Remaining issues after applying the MCC name alias counterfactual:
If MCC-21A-480V-3PH and MCC-21B-480V-3PH are treated as MCC-21A and MCC-21B, Jennifer Round 1, Diego Round 2, Jennifer Round 2, and the final matrix become perfect. Diego Round 1 still has extra intermediate control/signal nodes and four false-positive GT-node edges after the MCC alias correction.

Examples causing the raw drop:
- CB-MPA1 -- MCC-21A-480V-3PH was extracted, but the GT expects CB-MPA1 -- MCC-21A.
- MCC-21A-480V-3PH -- PUMP-CCW21A was extracted, but the GT expects MCC-21A -- PUMP-CCW21A.
- CB-MPB1 -- MCC-21B-480V-3PH was extracted, but the GT expects CB-MPB1 -- MCC-21B.
- MCC-21B-480V-3PH -- MOV-RWST21B was extracted, but the GT expects MCC-21B -- MOV-RWST21B.
- Diego Round 1 also inserted extra intermediate nodes: RPS-CH-A-CONTROL-LANE, RPS-CH-B-CONTROL-LANE, VOLTAGE-SIG-A, and VOLTAGE-SIG-B. These split several GT relay/RPS and voltage-signal edges into two-hop paths.
