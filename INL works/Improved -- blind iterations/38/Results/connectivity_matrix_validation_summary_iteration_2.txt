Connectivity matrix validation summary - Document 3, Iteration 2

Ground truth normalization:
The GT file is an edge list, so it was normalized into an undirected set of component-to-component edges before validation. The extracted CSV files were adjacency matrices and were normalized into the same undirected edge-set format. Diego/Jennifer round matrix files and final_connectivity_matrix.csv were evaluated.

GT after normalization: 60 undirected edges across 55 component names.

Main reason the scores were not perfect:
The non-perfect scores were caused by connectivity/edge discovery errors, not component naming. All GT component names were present exactly in every evaluated matrix, no GT components were missing, and no extra non-GT/intermediate nodes were introduced. Every evaluated matrix had the same mismatch pattern: one incorrect extracted edge and six missing GT edges.

Incorrect extracted edge causing FP:
- BUS-120AC-B -- RELAY-27B

Missing GT edges causing FN:
- BUS-120AC-A -- TR-CPT-A
- CB-103 -- RELAY-86A
- CB-104 -- RELAY-86B
- CB-201A -- RELAY-27A
- CB-201B -- RELAY-27B
- GND-STA -- TR-201A

What was not responsible:
- Component names were not wrong or close-but-imperfect; every GT component name appeared exactly.
- No GT components were missing from the extracted matrices.
- No extra intermediate/non-GT nodes were inserted into the extracted matrices.
- No false negatives were recoverable as a two-hop path through an intermediate node.

Examples causing the drop:
- BUS-120AC-B -- RELAY-27B was extracted, but that direct edge is not in the GT, so it produced the only FP in each matrix.
- Several relay/control GT links were not discovered: CB-103 -- RELAY-86A, CB-104 -- RELAY-86B, CB-201A -- RELAY-27A, and CB-201B -- RELAY-27B.
- BUS-120AC-A -- TR-CPT-A and GND-STA -- TR-201A were also missing in every evaluated matrix.

Counterfactual performance:
Because there were no extra nodes, removing non-GT component nodes would not change the score. The useful counterfactuals are: remove the incorrect FP edge, add the missing GT edges, or do both.
